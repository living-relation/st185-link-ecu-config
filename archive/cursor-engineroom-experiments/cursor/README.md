## Rules for agents

- Never read these as a source of truth. The chain is in
  `docs/RECONCILIATION-RULES.md`: `XTREMEX-IO-TABLE.html` → `SCHEMATIC-WIRING.html`
  + `apps/harness-schematic/` → `docs/harness/*.harness` → harness.design mirror.
- Never feed these to `buildlist.py` or `buylist.py`. Both read explicit
  filenames in `docs/harness/` and must keep ignoring this folder.
- Mine them for facts and part numbers if useful, then land the fact in the real
  file. Do not copy geometry or layout out of them.
- Delete a file here once its content has been folded into the real diagram.
