Two notes on the numbers.
  • Retailers list this unit as "74 mm". The plate says 745. Use 74.5 mm for the flange step and any airflow work. Same part, rounder number.
  • The Bosch Motorsport ETB data sheet lists bores of 32, 40, 44, 46, 52, 54, 60 and 82 mm and does not name 0 280 750 474. This is the Porsche/VAG production unit the motorsport trade resells. The electrical figures below are inherited from that platform data sheet, not from one naming this part. Verify both sensor voltages on the bench before trusting them.

The two tracks run in opposite directions at the same gain. Their sum is nominally a constant 5 V — that is the redundancy check. If Pot 1 + Pot 2 drifts away from 5 V, one track has failed. This is why the G4X needs both configured with the correct orientation: swapping them or calibrating one backwards defeats the check without producing an obvious symptom.

Subaru BRZ pedal — the trap

The BRZ pedal is a Toyota-family design, and Link's help file warns about exactly this family:
"Some Accelerator Position sensors have one signal that stops changing before full travel is reached, these sensors are most often found on Toyota and Lexus engines."

"APS(Main) MUST be assigned to the signal that changes over the full working range and the other signal assigned to APS (Sub). Under no conditions should the orientation and these two signals be swapped."
Action: measure both pedal tracks across full travel before assigning them. If one track stops rising at roughly 60–70 percent, that track is APS (Sub), and PCLink's APS (Sub) 100% must be set to the APS (Main) percentage where it stops — not left at the default 100. Getting this wrong produces a permanent APS tracking-error fault and an 1800 rpm limit.

Aux 9/10 is the right choice and is not arbitrary. Link's help file: "Aux1/2 & Aux3/4 require an External Ethrottle Controller whereas Aux9/10 has a built in controller and can be connected directly to the EThrottle motor." The current allocation uses the built-in H-bridge. Nothing extra is needed.
Supply and ground. Nine sensor loads share the +5 V rail on A32: MAP, TPS×2, APS×2, three pressure transducers and the fuel-level divider. Confirm the XtremeX rail current limit against that total. If it is marginal, the DBW sensors take priority — Link raises fault code 72 (Analog 5V Supply Error — E-Throttle) and shuts the throttle down if the rail sags. DBW sensor ground must come from a Gnd Out pin, not a chassis ground, so the reference tracks the ECU.

Calibration procedure — do not reorder these steps

  1. Wire everything per the schematic.
  2. Remove the ETB power relay before first power-up. This stops the motor being driven unexpectedly.
  3. PCLink → E-Throttle Mode = Setup Mode.
  4. Set PWM Output = Aux 9/10. Set EThrottle Relay = Aux 2.
  5. Set PWM Frequency (500 Hz to 1 kHz typical), Max Clamp and Min Clamp.
  6. Build the E-Throttle Target Table. Y axis = APS (Main), X axis = Engine Speed. Start 1:1. Use a 0 percent target at 0 percent APS so the G4X idle control works properly.
  7. APS window: Main Source = An Volt 4, Sub Source = An Volt 5. Assign Main to the full-range track.
  8. Set APS (Sub) 100% — see the pedal trap above. Then run APS Calibration, or enter the four voltages manually.
  9. TPS window: Main Source = An Volt 2, Sub Source = An Volt 3.
  10. Reinstall the ETB power relay. Stand clear; the plate can snap open.
  11. Run TPS Calibration with the bore clear. If PCLink reports the H-bridge polarity is reversed, fix it by inverting the Active State of Aux 9 — do not swap the motor wires.
  12. Tune the PID gains. Link's typical starting points: P 7.00, I 0.145, D 25.00, Max Clamp 90 %, Min Clamp −90 %. All must be checked on this throttle body.
  13. Set E-Throttle Mode = ON. Clear ECU fault codes. Confirm none return.
Setup Mode disables every safety feature. The car must never be driven in Setup Mode.

Fault behaviour

With mode ON, any e-throttle fault shuts the throttle down and applies an 1800 rpm limit. It will not restart until ECU power is cycled or the mode is changed.

CodeFault

72Analog 5 V supply error
75TPS versus target error
76TPS (Main) / TPS (Sub) tracking error

Analog fault thresholds. Set Error Low and Error High on all four DBW analog channels. Link's typical values are 0.1 V and 4.9 V, tightened toward the sensor's real working range where possible. Fault Delay defaults to 1 second — leave it there unless there is a reason.

Key-off reset. Aux 6 holds the EFI main relay so the ECU stays powered after key-off, letting the throttle return to its default position under control. That is why Aux 6 exists. It must not be reassigned.

5.4 Intelligent air conditioning control

Decision from Dan, 2026-08-31: document both control paths in parallel, fully specified. Neither is ruled out. He will choose after testing. This replaces the earlier "Option A preferred, Option B fallback only" framing. Both go into AC-CONTROL.md as equal, complete designs, and Option B's pin cost is treated as a real reservation.

From AC amplifier input signals.txt — the OEM amplifier has its own sensors and takes these inputs: ignitor/tach, coolant temp switch, vent outlet/cabin temperature, evaporator core thermocouple, trinary high/low pressure switch, and an ECU cancel/request signal.

Option A — through the OEM amplifier

ItemDetail

Option B — full Link ECU control

The ECU replaces the amplifier entirely and drives the compressor clutch itself. It must therefore take over every protection the amplifier used to provide.

ItemDetail
Clutch driveAux 4 (A18), low-side, grounds the A/C clutch relay coil directly. Same pin as Option A, different job.
Trinary pressure switchOne An Volt. An Volt 10 (spare) is the natural home.
Evaporator core temperatureOne Temp channel — but Temp has zero spare. Either move the charge-pipe IAT off Temp 4 to An Volt 11 as a 0–5 V part, or use An Volt 11 directly with a thermistor and a divider.
Cabin A/C requestSwitchboard SW_MASK bit 1 over CAN — no ECU pin needed. Already allocated; works for either option.
Condenser fanIgn 5 (B13) as a spare-ignition low-side output. Same for both options.
Extra ECU pins versus Option A2 — one An Volt for the trinary, one channel for the evaporator sensor
Pin headroom after Option BAn Volt: 2 spare → 0 spare. Temp: 0 spare → 0 spare, or −1 if the charge-pipe IAT is not moved first.
Tune logic Option B must implement, which the amplifier currently does for free:
  1. Low-pressure cut-out — disengage below the trinary's low threshold, protecting the compressor from running with no charge.
  2. High-pressure cut-out — disengage above the high threshold.
  3. Evaporator freeze protection — disengage as the core sensor drops toward 0 °C, re-engage with hysteresis. Without this the evaporator ices and airflow stops.
  4. Cycling hysteresis — minimum on-time and off-time so the clutch does not chatter.
  5. Condenser fan trigger — fan on with the compressor, and above a pressure threshold.
  6. Load-based cancel — the same high load / wide throttle / boost cancel as Option A.
  7. Idle handling — with DBW this is a throttle-target offset, not an ISC duty, applied on clutch engagement so the engine does not dip.
The thing that would make Option B a bad decision is doing it without items 1 to 4. The amplifier is not just a relay, and replacing it means replacing what it protects against.
Honest comparison. Option A costs one pin and inherits proven protection. Option B costs three pins and moves compressor protection into a hand-written tune. Option B gives finer control, full A/C state on CAN, and removes a 33-year-old module from the system. Both are legitimate.

Practical testing order. The two options share Aux 4 and differ only in what it connects to plus two extra sensor inputs. Option A can be wired and tested first, and Option B adopted later by adding the trinary and evaporator inputs and rerouting Aux 4 — provided An Volt 10 and 11 are reserved now and not given to anything else.

Recommendation: reserve An Volt 10 and An Volt 11 for Option B. If Dan settles on Option A, release them.

5.5 Electric power steering pump

Current allocation: Aux 7 (A27), low-side pulse output, direct to the MRS pump SPD pin (yellow/white), no series resistor, with speedo-out scaling set so the pump idles down above roughly 10 km/h.

Researched factDetail
Signal originNormally from the combination meter, not the ECU
Pulse rate4 pulses per revolution
VoltageUnresolved — 0–5 V reported for a related RAV4 system, 0–12 V reported for MR2 units
Required?No. Without it the pump winds down slowly on its own. With it, assist reduces at speed and reacts faster.
GapDetail
Signal voltageA low-side output pulls to ground and floats when off, so the high level is set by whatever pull-up the pump provides. If the pump has none, a pull-up to 5 V or 12 V is required — which contradicts the "no external pull-ups needed" claim in the I/O table. Measure it before wiring.
Scaling4 pulses per wheel revolution must be converted to a Link speedo-out frequency. Tyre rolling circumference and final drive ratio are needed and are not recorded anywhere.
Source of speedFour ABS wheel-speed sensors on DI 3–6, marked proposed. Google Drive #36 names Highlander sensors at the rear, Camry at the front. Confirm they are the two-wire reluctor type the ECU can read.
Idle-upOther ECU IO and MATH.txt calls for "inverse of VSS out — idle up for EPS power draw". With DBW this becomes a throttle-target offset, not an ISC duty. Not yet written as tune logic.

5.6 Proposed new CAN frame 0x3F2

The three cluster-facing frames are frozen. The three RealDash frames 0x3EF–0x3F1 are full. Five of the eight values below have nowhere to go. Rather than disturb anything frozen, add one new ECU → RealDash frame.

0x3F2 (decimal 1010) — DBW, A/C and Chassis Extended. ECU → RealDash. 100 ms. Custom, BigEndian.

ByteFieldTypeScaleOffsetSource
0ETB target position %uint810ECU E-Throttle target
1ETB actual position %uint810TPS main
2Accelerator pedal %uint810APS main
3DBW fault codeuint8100 = OK; nonzero = Link throttle-error code (69–86)
4Lambda controller statusuint810CAN-Lambda module status/error
5Cabin temperatureuint81−50ECU echo of switchboard 0x640 — restores the value dropped from 0x3F0
6EPS speed-out duty %uint810What the ECU is sending to the pump
7A/C cancel stateuint8100 = not cancelling, 1 = cancelling
Why this is safe. 0x3F2 is inside the block the allocation table already marks "0x3F2–0x63F reserved / available". It is ECU-transmitted only. The cluster does not decode it and needs no firmware change. Only link_g4x_realdash.xml and the LCS/JSON pair change.

Byte 5 does not break the routing rule. The switchboard still talks only to the ECU. The ECU echoes. RealDash still reads only ECU frames. This is exactly the pattern already used for 0x3EF bytes 3 and 5.

11. Assumptions being challenged

  1. "No external pull-up resistors are required." XTREMEX-IO-TABLE.html states this as settled. It cannot be settled until the EPS SPD line voltage is measured. A low-side output cannot produce a high level on its own.

  3. Four ABS wheel-speed sensors on DI 3–6. This consumes four of ten digital inputs, is still marked "proposed", and carries a note that it "drops first". Committing four inputs to a feature that is first to be cut is worth reconsidering before the harness is cut.
  4. The interactive wiring app as a working tool. It has produced two saved states that disagree with each other and with the repo, and it has no backup. Right now it is a source of drift, not a cure for it. Either it becomes generated output from the repo, or it should be retired.
