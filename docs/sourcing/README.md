# Sourcing - what to pick, and in what order

Binding on every part choice in this project.

## Selection order

1. **What Daniel already owns.** `te-on-hand-bom.csv` in this folder. If a part on
   that list will do the job, it wins - even over a "better" part.
2. **TE Connectivity.** Preferred manufacturer for connectors, contacts, seals,
   backshells and heat shrink. Prefer parts TE offers **free samples** on.
3. **Daniel's approved suppliers** - the list in "Approved suppliers" below - when TE falls
   short or has too few options.
4. **Anything else**, and only then. Say in the BOM row why nothing above fit.

Every spec read off a non-maker listing is validated against the maker's sheet first; the non-maker short list and the
validation rules are in Trusted sources below (DECISIONS R167).
A number with no maker sheet, official model or measurement behind it is marked UNVERIFIED. A part description describes
the part, never its use. In the BOM, labels are not priced (DECISIONS B21).

Never spec a new connector family without checking step 1 first. This project
already owns HDP20, HD30, Deutsch DT, SuperSeal and AMP MCP hardware.

**The one shopping list is `PROJECT-BOM.xlsx`** (generated by `build_project_bom.py`; buy links and prices are kept in `bom-links.csv`).

### An HD30 pair is already on the shelf, unassigned

`HD34-24-21SN` receptacle + `HD36-24-21PN` plug - shell 24, 21 positions,
contact sizes 12/16. Nothing in the looms claims them.

Twenty-one ways covers the CSB3's 14 used terminals plus 7 spare exactly, and it
takes the size-16 contacts already in stock instead of 26 size-20 that are not.
Two things to weigh before adopting it in place of the 6.40 HD34-24-33PE /
HD36-24-33SE pair:

- **No room to bring out all 26.** 6.37 brings out the 12 unused CSB3 channels so
  a spare never means opening the box. Twenty-one ways gives 14 + 7 instead.

Daniel's call. Flagged, not decided.

## Digi-Key pricing (API)
`docs/sourcing/digikey_price.py` looks up every BOM line that has a real part number and no real price through the Digi-Key Product Information v4 API (2-legged OAuth). Keys are read from `~/.secrets/digikey.env` and never printed or stored in the repo. Results land in the untracked `_research/digikey-results.json`; `docs/sourcing/merge_digikey.py` writes the exact-match unit price (at the BOM quantity, cheapest package), product URL and stock into `bom-links.csv`; then run `build_project_bom.py`. Parts Digi-Key does not carry (RS, Klauke, PEM, Tefzel wire, Aptiv, Toyota, Bosch, CNLINKO, battery cable) are left as they were. Digi-Key does not publish a free-sample flag, so the "Free sample" column stays TE-only plus `sample_other` entries in `bom-links.csv`.

## Small-vendor pricing (Shopify stores)
`docs/sourcing/shop_prices.py` reads the public `products.json` of KSV Looms, Custom Connector Kits and Race Spec Online and prices every still-unpriced BOM line whose part number equals a vendor SKU (terminals: the loose-piece listing, not the reel; DR-25 tubing is per foot and converted to the BOM's metres). Toyota and Bosch lines use the vendor's "same as" kit and say so in the price basis. Run it after `merge_digikey.py`, then `build_project_bom.py`.


## Trusted sources

Living list (Dan, 2026-10-18; DECISIONS R167). Maker data always wins: the maker's spec sheet, customer drawing,
application spec or official 3D model (a maker sheet hosted on a listing site counts). This list is only for the
non-maker sources used when no maker sheet exists, and for availability / price.

- A part spec read on a non-maker listing is validated against the maker's sheet (usually a PDF) before it is used.
- No maker sheet: use a source on this list with the right tag. Not on the list either: confirm the spec with two more
  independent sources. Search-engine result snippets never count.
- Terminal wire ranges (AWG / mm2 min and max) are often wrong off the maker's site: always validate them. Terminals rarely
  take one gauge; if only one gauge seems to fit, look again or look for the sibling part number.
- A vendor's "recommended / compatible parts" list is a fine place to start; its parts still need validating unless the
  vendor is on this list with that tag.
- Once a part number is validated, also search it on Amazon, AliExpress and eBay for cost and availability (shopping only:
  the listing's specs are not used).

Trust ranks: **1** — its data for the tagged categories can be used as it stands (still loses to maker data). **2** — usable after one independent cross-check. **3** — leads only (part numbers, prices, stock); every spec is validated against the maker. Tags: terminals, connectors, relays, fuses, CAD models, cross-reference, availability.
