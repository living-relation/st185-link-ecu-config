The scheme (the ONE home; `docs/harness/README.md` points here):
  1. **Code.** Every wire belongs to one circuit - the fuse box circuit it is fed through (FAN, HTR, SW12 ...); a relay's coil-minus (85) wire and a load's ground return belong to the circuit they switch / return; an ECU loom wire belongs to the device it serves (MAP, INJ1 ...). The code goes in the wire's `identColors` (the app draws it along the wire, https://docs.harness.design/component/wire#assigning-idents). The app holds one ident list per wire, so both ends carry the same code.
  2. **Reading it.** On the car the circuit's code sits at EVERY end of the circuit - every end of every wire in it: connector, terminal, splice and broken-off end - 6 mm bands, band 1 next to the end, so it reads the same from any end, outward. Multi-band codes are expected (Dan, 2026-10-14: "you can do more than one colored band per circuit. you might have to actually. use the bands at all ends of the circuit."). A cut or loose wire is matched end to end by its code.
  3. **Allocation.** A code is unique among the circuits of one drawing; a circuit name has one code in every drawing; a broken-off pair (`interfaces.json` "breaks") carries the same circuit on both sections, chosen by the drawing that feeds it (the fuse box or ECU side) and copied by the other. Shortest codes go to the circuits with the most wires (1 band, then 2, then 3; 4 only when a drawing runs out). The circuit and its wires are listed in `docs/harness/interfaces.json` "identBands" (the app rejects unknown keys, so the name cannot live in the drawing); listing a harness there means it is done, and every wire in it must then be listed.
  4. **Parts (R82, real and buyable).** TE Raychem RNF-100 2:1 tubing, 1.2 m sticks, cut into 6 mm bands: 20-14 AWG `RNF-100-3/32-6-STK` / `-4-STK` / `-9-STK` (blue / yellow / white, 2.4 mm expanded, 1.2 mm recovered); 12-8 AWG `RNF-100-3/16-6-STK` / `-4-STK` / `-9-STK` (4.8 / 2.4 mm). Wires 6 AWG and heavier carry no band (no stock band fits; they are few and named by their label).
