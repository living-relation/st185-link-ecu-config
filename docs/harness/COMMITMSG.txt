EPS and MRS are the same device - name it that way

Daniel caught me listing "EPS" and "MRS" as two separate things in a loom C zone
summary. They are one device: the MR-S (ZZW30) electro-hydraulic power steering
pump, control module bolted to the pump, living in the engine bay.

Four nodes, one device:

  k_eps     its relay, HCR150, mounted beside the pump
  mrs_pwr   connector A, main power, 90980-12068
  mrs_ctrl  connector B, signal, 6-way, PN still unidentified
  mrs_en    connector C, ignition, 90980-10942

The old labels read like two unrelated systems - "EPS pump relay HCR150" next to
"MRS EPS pump power" - which is how the mistake happened in the first place. All
four now say MR-S EHPS pump and name which connector they are.

Added gp_mrs_ehps, the GroupPart that records the device, per the devices guide.
The editing tools cannot create the Group itself, so that is a one-time job in the
app: select those four nodes, group them, assign the part.

Naming authority is docs/devices/SENSOR-AND-ACTUATOR-REFERENCE.md, which spells it
MR-S EHPS. The harness had been spelling it MRS.
