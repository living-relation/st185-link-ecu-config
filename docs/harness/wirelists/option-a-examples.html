Splice column examples (Option A)

Example circuits only, not the ST185 wiring. Each drawing has one wire table under it, written the Option A way.

The rules

The Option A rules live in one place: docs/harness/redesign/DECISIONS.md, section "Wire lists". This page only shows them at work.

1. Splices at both ends of the harness

One feed fans out at each end: 2 loads at the fuse end, 3 at the ECU end, joined by one link wire.

This is where Option A gets clumsy: with no single home end, "legs of SP-x" stands in for the far side. It still reads, and the Net column ties all six wires together.

2. Spliced wire continues into another harness file

The engine harness carries a sensor 5 V lead to the bulkhead. The cabin harness picks it up at the same bulkhead pin and splices it into the ECU's 5 V splice.

If the splice sat in the engine file instead, w20 would be the leg (Splice = SP-5V) and w21 would be a plain bulkhead-to-ECU wire. The bulkhead pin is always where one file hands over to the other.

4. CAN trunk with a drain that runs on, and five node branches

A 2-core shielded CAN trunk leaves a 5-pin connector X1. Its drain does not pin into X1: it runs on to a shield splice on connector X2. At the far end the trunk splits at three splices into five branches. Each branch carries CAN H, CAN L and the shield to its node, and every branch drain floats at the node.

NODE-2 to NODE-5: the same three rows each (n2_h ... n5_sh)

Flag: this layout is a star with five stubs. On a 1 Mbit/s CAN bus (ISO 11898-2) each stub should stay under about 0.3 m, or the reflections corrupt frames. If the branches are longer than that, daisy-chain the nodes instead (the bus goes in and out of each node) and put the two 120 Ω terminators at the two far ends.
