TE's own DRB12-102PAE-L018 part page links four deeper documents by exact number: Application Specification 114-151021, Engineering Report 502-151021, Product Specification 108-151021, and Qualification Test Report 501-151021 — any of these could carry unmated sealing, an itemized fluid list, and salt-spray duration. All four are served through TE's DocumentDelivery/DDEController endpoint, which returned an empty response to a direct fetch (no readable text or PDF content) — same result as the first attempt. This looks like a JS-gated or session-gated delivery system rather than a plain static file link, so it is outside what an automated fetch can retrieve.

These three items are marked "not published (per TE spec 108-151021 / 501-151021 — gated, not retrievable)" below, rather than "not published" outright, so a follow-up request to TE support or a distributor (Digi-Key, Mouser, LADD) has the exact document numbers to ask for.

Bottom line

On every spec that has a clear number from TE — temperature, mated sealing (IP68 + IP6K9K), vibration, shock, thermal cycling, mating durability, and per-size contact current — the DRB 102-way clears a firewall/engine-bay location with margin. Nothing found so far disqualifies it. Implementation proceeded on this basis, per Daniel's 2026-09-29 direction above.

Three items (unmated sealing, an itemized fluid list, salt-spray duration) simply aren't published on TE's consumer-facing pages for this part, and a second attempt at the specific documents that likely carry them (Product Specification 108-151021, Qualification Test Report 501-151021) confirmed those documents exist and are named on TE's own part page, but are served through a document-delivery endpoint that returned nothing retrievable. That's a documentation-access gap, not a known failure. The connector's SAE J2030 compliance is a reasonable proxy that this kind of testing was done.
