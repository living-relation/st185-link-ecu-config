A/C amplifier A15 circuit test

Compressor A/C amplifier A15, behind the glove box (1993 ST185). Source: 1993 Celica Service Manual (Mitchell) - Electrical, "A/C-Heater System - Automatic", A/C AMPLIFIER CIRCUIT TEST, PDF p.25-26 (table p.26, connector face Fig. 4 p.28); the manual-A/C article has the same test on p.6-7 (Fig. 5). Repo copy: st185-celica-repair-manual/manuals-electrical/. No bench test is planned (Dan 2026-10-25): the wiring is assumed right and this test is run in the car later.

What this is: a harness-side check with the amp unplugged, not a powered test of the amp itself. It proves every wire the amp needs is there and right, including the new RPM feed and the compressor lock sensor.

Set-up

1

Unplug A15

Disconnect the 18-pin A/C amplifier plug. All readings are on the harness side of the plug. Face (Fig. 4): top row 1-2, 3-4, 5-6, 7-8; bottom row 9-10, 11-12, 13-14 (centre), 15-16, 17-18.
2

Set the controls

Ignition ON, temperature dial at max cool, blower on HI. Pin 18 also needs the engine running.
3

Measure each line below

A reading off spec means that circuit has a fault: repair the wire, not the amp.
