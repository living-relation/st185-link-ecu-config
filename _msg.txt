Remove Caliber entirely

Caliber was costing more than it returned here. Its refresh needs an LLM
provider, the repo has no API key, and with real changes to process the
pre-commit hook stalled for about ninety seconds on every commit. Its value
was also lower than advertised for this project, whose truth lives in
markdown and .harness JSON rather than in code it can read.

Removed: the git pre-commit hook (it contained nothing but the Caliber
block), all eight Caliber hook groups from .claude/settings.json, the Cursor
hooks.json (entirely Caliber), the .caliber state directory, .caliberignore,
CALIBER_LEARNINGS.md, the caliber-sync GitHub workflow, the setup-caliber
skill in all three agent directories, the find-skills and save-learning
skills which shell out to the caliber CLI, the three caliber-*.mdc Cursor
rules, and the four caliber:managed blocks in each of CLAUDE.md and
AGENTS.md.

Kept everything of ours: CLAUDE.md and AGENTS.md themselves including the
reconciliation banner, the four project Cursor rules and their Claude
counterparts, the four project skills, and the permissions block in
.claude/settings.json.

Preserved two references that only existed inside Caliber's files: the local
checkout path from CALIBER_LEARNINGS.md now lives in CLAUDE.md, and the
model-pinning guidance from the managed block survives as a plain Model
section in both files.

Corrected two of our own docs that cited Caliber's external-source feature
for resolving cluster-repo paths. They now name the sibling checkout path
directly, since that mechanism is gone.
