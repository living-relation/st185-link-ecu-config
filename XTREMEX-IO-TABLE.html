Drive types: Aux 1–4 = low-side only. Aux 5–8 = high or low side. Aux 9–10 = H-bridge (ETB). Spare Ign/Inj = low-side. Low-side outputs sink to ground when active and float (hi-Z) when off — no forced high, no pull-up unless a device needs one. Active-HIGH loads must use Aux 5–8 (or a relay). Verify wire colors on the official loom diagram.
✔ Confirmed hardware
  • Crank trigger: Toyota OEM reluctor (VR) on 36-2 crank wheel (Beams/5S) → Trigger 1.
  • Cam trigger: RacerX MR2 kit, Cherry Hall, intake cam, single tooth → Trigger 2.
  • Ignition: 1ZZ coil-on-plug (built-in igniter, logic-level) → Ign 1–4. No distributor.
  • Injectors: 1400cc ATS/Bosch top-feed, flow-matched (hi-Z → saturated) → Inj 1–4.
  • Throttle: Bosch Motorsport 74mm ETB → motor Aux 9/10, TP main+sub + APS main+sub on An Volt, power via V-Ethrottle (relay Aux 2).
  • Flex sensor: Continental 3-pin (freq) → ethanol % and fuel temp (no separate fuel-temp sensor).
  • Starter: ECU-controlled — start input + start-relay output; ECU disables the start relay in software under set conditions (no separate cut relay). EFI main relay held by ECU for DBW key-off reset.
⚠ Output power routing
  • Switchboard outputs = 4× low-side @ 0.5A (LED level) only. Use it for switch/analog inputs over CAN + tiny LEDs — never fans/pumps/relays.
  • All power loads on the ECU (Aux + spare Ign/Inj → external relays, active-low). Overflow → ECUMaster PMU/PDM on CAN 1.
  • Switch inputs → switchboard (brake, reverse, cruise) to keep ECU DIs for frequency inputs.

AC control (per your AC-amp notes)

ECU does not drive the compressor. Aux 4 is a low-side output that either grounds the AC clutch relay coil (float = off) or feeds the amp's ACT cancel input — active-low, floats when inactive, no pull-up. Used to cancel the compressor under high load/throttle/boost. No AC-on input — the XtremeX closed-loop idle absorbs the AC-load dip in software. Confirm whether Aux 4 grounds the clutch relay directly or feeds the amp ACT input, so we set the polarity right.

External pull-up resistors

None required in the current plan. The flex sensor supplies fuel temp, which freed a Temp input, so every thermistor (ECT, IAT, oil, charge-pipe IAT) uses the ECU's built-in pull-ups. The MRS speed-out and AC-kill are low-side pulse/sink outputs that need no resistor. Add one only if a specific device's datasheet calls for it (e.g., verify whether the RacerX cam-Hall kit already includes its own pull-up — per its instructions).
