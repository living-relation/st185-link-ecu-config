TrackCluster RealDash — CAN Bench Test Tool

Fakes the Link G4X ECU's RealDash frames (0x3EF–0x3F1): pick a gauge, type the value it should show, get the raw CAN frame to paste into CANgaroo, PCAN‑View, SavvyCAN, or any slcan/candleLight app. Signal math mirrors link_g4x_can_setup.json / link_g4x_realdash.xml — not a placeholder map. RealDash is a passive listener, so these are the only three ECU frames it decodes.

Bus settings (same for every frame)

Bitrate1,000,000 bps (1 Mbit/s)
ID typeStandard / 11‑bit (every ID below is < 0x800)
Frame typeData frame (not RTR)
DLC (data length)8 bytes, always — pad with the zeros shown
Byte orderBig‑endian — already baked in, paste the hex left‑to‑right as shown
CANgaroo (candleLight/CANable): Connect → Bitrate 1000000 → Connect. New frame → ID (hex), Standard, DLC 8, paste data bytes.
PCAN‑View (PEAK PCAN‑USB): Connect → Baud rate "1 MBit/s". Transmit → New Message → ID hex, Standard, DLC 8, data bytes.
SavvyCAN (CANable/SLCAN and most adapters): Connection → bus speed 1000000. Send window → CAN ID hex, Extended off, 8 data bytes.

What this covers

0x3EF (50 ms)Target λ, Throttle, TC setting/intervention, Boost map, Cruise, A/C
0x3F0 (100 ms)Fuel/Charge‑IAT temps, Engine load, Coolant P (u16), Ethanol, Turbo speed, Trigger errors
0x3F1 (50 ms)G‑force X/Y/Z + 6 extended warning bits (packed in byte 6)
Each frame below carries several gauges together — a real ECU sends all its fields in one message, so fill in everything you care about in that card, then copy the one 8‑byte frame. Fields you leave alone use safe idle defaults, not zero. These frames intentionally exclude anything the ESP32 cluster already shows (RPM, boost, ECT, speed, gear, …).
Send 0x3EF and 0x3F1 every ~50 ms and 0x3F0 every ~100 ms (matching each card's period) so RealDash sees fresh values — link_g4x_realdash.xml sets a 2000 ms frame timeout that forces every value in a frame to its offline reading if the ECU stops broadcasting. Formulas mirror link_g4x_can_setup.json, inverted to compute the raw wire bytes from the display value you type. RealDash is listen‑only; this tool exists to stand in for the ECU on the bench.
