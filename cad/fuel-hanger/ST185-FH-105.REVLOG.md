# Rev log

One row per release (PR) of each model, oldest first. Clerical revs are not listed. Rev A is always "Initial".
Source: the evidence column of `cad/DRAWING-REVS.md`. Date = PR merge date, America/New_York, dd/mm/yy.
By = the initials of the person who requested the change (DG for this project; never an agent or tool name, DECISIONS R200). The drawing shows the
newest rows in its Rev log table (top right, sheet 1); this file keeps the full history.
One file per model (<part no>.REVLOG.md beside the model's STEP), read by the handbuilt-cad drawing engine (cad/drawings/specs_1017.py).
Fuel hanger rows A-F are the fairsolid run folders (`runs/fuel_hanger_billet_1014`, rev1 = root, rev2..rev8; not in git).
Their dates are from each folder's SUMMARY.md title.
