# Rev log

One row per release (PR) of each model, oldest first. Clerical revs are not listed. Rev A is always "Initial".
Source: the evidence column of `cad/DRAWING-REVS.md`. Date = PR merge date, America/New_York, dd/mm/yy.
An assembly release = a PR that released any of its fabricated parts (the ST185-FH-100 rule); the row names each part and the
letter that PR gave it. First assembly drawing: the buildability review, 2026-10-18 (DECISIONS R181).
