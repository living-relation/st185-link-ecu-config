# Rev log

One row per release (PR) of each model, oldest first. Clerical revs are not listed. Rev A is always "Initial".
Source: the evidence column of `cad/DRAWING-REVS.md`. Date = PR merge date, America/New_York, dd/mm/yy.
By = who made the change (commit trailers; "unknown" where the history doesn't say). The drawing shows the
newest rows in its Rev log table (top right, sheet 1); this file keeps the full history.
One file per model (<part no>.REVLOG.md beside the model's STEP), read by the stevecad-tools drawing engine.
